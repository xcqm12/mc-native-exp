mc-native-exp · 原生启动实验

围绕一个问题做实验：拿到官方全套 Minecraft 文件与正版账号后，启动能否不依赖 JVM？
当前版本 v0.0.1.beta（版本方案：patch 逐次 +1 至 .9 后进位，全程带 beta 后缀）。

① 官方全量下载 + 正版账号

  • piston-meta 全版本清单（实测 925 个版本），client / libraries / assets / natives 全套官方源下载，SHA1 流式校验 + 断点续传
  • 微软设备码登录 → Xbox → Minecraft services → 所有权校验：无正版账号实验拒绝继续

② 四大模组加载器自动安装

  • install fabric 1.21.4 / install quilt … — meta API 直装，无需 Java
  • install neoforge … / install forge … — 官方安装器 + 自动下载 Adoptium JRE 跑处理器
  • 安装全部写入项目 data\，不碰系统目录；launch <id> 正版会话启动（G1 优化参数 + smoke 模式）
  • OptiFine / LiteLoader（补丁型 / 停更）不在自动安装范围

③ 脱 JVM 可行性研究（解释器原型）

  • Rust 手写 Java class 文件解析器（JVMS §4，常量池 17 种 tag 全覆盖）
  • 字节码解释器逐条解释官方 client jar——数据表明几百~几千条指令即撞墙：JNI / invokedynamic / JDK 语义
  • 结论：转译路线工程量以人年计；可玩的「无 Java MC」现成方案是 Horizon（Aurora 已集成）
